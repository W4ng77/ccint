| `rules_v2` 独有 | 20 | 20 | 10 | 0.500 | 0.474 | ≈ 0.30 |

加权方法：把各分层格子的试点 CSR 按该格子在总体中的占比加权。
这只是参考值，因为各格子的样本很小（5 到 29 个）。完整采集之后可以直接计算，不再需要估计。

**观察（仅描述，不做因果解读）：** 原始采集时刻的计数快照，几乎完全决定了试点里有没有对话。

- 主种子中，快照回复数和引用数都为 0 的 29 个种子，这次采集**全部**是 0 次对话；
- 快照里有回复或引用的 36 个种子中，有 35 个这次确实有对话。

原始采集时刻的 `replyCount` 与本次重采的结果相比：98 个种子一致，1 个变多，没有变少的。

## 需要评审决定的事项（Gate A 与 Gate B）

1. **Gate A（采集质量）**：从试点看，各项条件都满足：重建可靠，错误可度量，partial 可以区分，翻页可用，边的派生可复现。
   唯一没有实测的是 429 限流分支。
2. **Gate B（互动稀疏度）**：主种子集的加权 CSR 约为 14%，也就是约 86% 的种子没有任何回复或引用。
   按 SPEC §51，如果完整采集证实了这个比例，互动稀疏本身就应当作为一项发现来报告；
   至于是否要强行做互动分类研究，需要在完整采集后再判断。
3. **完整采集的范围**：原始计数快照对「有无对话」的预测几乎是完美的。但 SPEC §10 要求区分「采集失败」和「确实为零」，
   所以即使预期为零的种子也必须实际观测，**仍然建议 2,631 个种子全部采集**，而不是只采快照里有互动的那部分。
